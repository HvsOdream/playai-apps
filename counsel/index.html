기기 간 동기화

같은 암호를 넣은 기기끼리 학생 명단·상담 기록이 합쳐집니다(아이패드↔노트북). 기록은 이 기기 안에서 암호화된 뒤 학과 중계 서버에 저장되며, 암호를 모르면 서버 관리자도 내용을 볼 수 없습니다. 암호를 잊으면 복구할 수 없으니 안전한 곳에 적어 두세요. 비워 두면 동기화하지 않고 이 기기에만 저장합니다.

데이터

기록은 이 기기의 브라우저 안에 저장되고, 동기화 암호를 설정한 경우에만 암호화된 사본이 서버에 올라갑니다. 브라우저 데이터를 지우면 이 기기의 기록은 삭제되니 백업 파일도 가끔 내려받아 두세요.

사용 안내

  1. 학생성공관리시스템 → 마이페이지(교수) → 지도학생 현황 화면을 전체 선택(Ctrl+A) → 복사
  2. 이 앱 → 학생 → 명단 가져오기에 붙여넣기 → 학생이 자동 등록됩니다
  3. 상담 시 새 상담 → 학생 선택 → 마이크 → 끝나면 상담일지 생성
  4. 결과 화면의 주 호소내용·상담내용 복사 버튼으로 시스템 상담입력 폼에 붙여넣고 저장
